---
name: api-compatibility
description: Проверка потребителей при изменении публичного API
---

Перед изменением публичного метода или формата ответа найди его потребителей в доступном коде. Для каждого несовместимого изменения укажи, какой вызов перестанет работать и как потребитель сможет перейти на новую версию. Проверь характерный вызов после изменения.
