---
name: use-shared-workspace
description: Work in the shared project tree and use the team's existing service instances.
---

Work in the current project tree. The user coordinates parallel tasks and assigns files to participants. Treat the files assigned to your task as available without repeatedly checking for concurrent edits. Keep changes within your task and preserve other participants' work.
If your task needs a file you know another participant is editing, explain the overlap and wait for the user's decision before editing that file. Do not create a separate worktree or stash another participant's changes.

Use the shared service instances on the ports configured for the project. When a service is already running, connect to it for development and verification. If it is unavailable or needs a restart, coordinate with the user first. Do not launch a private copy on a different port.
