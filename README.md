# Каталог материалов для агентов

Выбирайте отдельные файлы для своего профиля или проекта. Один и тот же материал можно использовать в нескольких проектах.

| Каталог | Когда подключать |
|---|---|
| rules/ | На всю сессию, например для работы с публичным API |
| prompts/ | По запросу пользователя, например для подготовки передачи задачи |
| skills/ | Когда задача требует описанной процедуры |

Перед предложением нового материала поищите тот же сценарий в `rules/`, `skills/` и `prompts/`. Ищите по действию, результату и синонимам, затем прочитайте ближайшие совпадения. Если материал уже описывает нужное поведение, дайте на него ссылку. Если упущен частный случай, дополните существующий материал. Отдельный файл нужен, когда агенту предстоит принять другое решение или выполнить самостоятельную процедуру.

Для нового правила или промпта создайте Markdown-файл с полями name и description в YAML-заголовке. Для скила используйте skills/<имя>/SKILL.md. При импорте архива NeuroBox классифицирует именованные правила и промпты как prompt, а SKILL.md как skill.

Материалы редактируются обычным Git-процессом. Для воспроизводимого подключения указывайте путь к материалу и ревизию репозитория.
